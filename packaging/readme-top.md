# OpenUtau NEUTRINO対応版 (非公式ビルド)

歌声エディタ [OpenUtau](https://github.com/openutau/OpenUtau) で [NEUTRINO](https://studio-neutrino.com/) の歌声(ずんだもん等)を鳴らし、画面で音程・歌詞・ピッチカーブ・ビブラートを直せるようにしたビルドを配布しています。
